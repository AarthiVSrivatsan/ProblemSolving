Lap Distance Tracker

A single loop, one running total, five checkpoints.

Difficulty: Beginner Concept: for / while loop Time: ~15 min

The problem

A runner is training on a circular track. Each time they complete one full loop of the track (a lap), they've covered a fixed distance, d metres. They train for n laps in a row.

Write a program that prints the runner's cumulative distance after every lap — not just the distance of that one lap, but the running total so far.

Picture it

Each lap = one pass through the loop body. The odometer only ever goes up.

Input / Output

Input

n = 5
d = 400

Output

Lap 1: 400m
Lap 2: 800m
Lap 3: 1200m
Lap 4: 1600m
Lap 5: 2000m

Constraints

  • 1 ≤ n ≤ 20 — number of laps
  • 1 ≤ d ≤ 2000 — lap length in metres
  • Use exactly one loop. No hardcoding the five output lines.
  • Print one line per lap, in order, showing the total distance so far.

Think about it before you code

Three things repeat every lap: a number goes up by one, a distance gets added to a running total, and a line gets printed. Everything else — the starting values, the stopping point — only happens once. That split is the whole idea behind a loop.
