Lists & For Loops

The two building blocks behind the Pass/Fail Counter exercise. Nothing here asks you to write and run code — just to understand what a list is, and what a for loop actually does with one, one item at a time.

What you need before Read the Code

Two ideas, one after the other — a list holds many values, a for loop visits them one at a time.

A list holds many values in one variable, in a fixed order. Instead of score1, score2, score3..., you get one name for the whole collection:

scores = [45, 32, 78, 40, 55, 21, 90]

Creating a list

Square brackets, values separated by commas: [45, 32, 78]. Order is preserved — the first value stays first.

Indexing

Every item has a position, starting at 0, not 1. scores[0] is the first item.

len()

len(scores) gives you the count of items — how many positions there are to visit.

Picture it

Each box below is one item in scores. The number underneath is its index.

scores[0] is 45 · scores[3] is 40 · scores[6] is the last item, at index len(scores) - 1

Reading from a list

print(scores[0]) # 45 — the first item print(scores[3]) # 40 print(len(scores)) # 7 — there are 7 items

A for loop walks through a list one item at a time, in order, without you having to track a position yourself.

for score in scores: print(score)

Each time round, score is reassigned to the next value in the list — first 45, then 32, and so on — until every item has been visited once.

Combine them

List + for loop + a condition

This is the exact shape behind the Pass/Fail Counter — a loop, a check, and a running result.

Adding everything up

total = 0 for score in scores: total += score print(total)

One running value, updated once per item. No indexing, no counting positions — just visit, update, repeat.

Counting matches

pass_count = 0 for score in scores: if score >= 40: pass_count += 1 print(f"Passed: {pass_count}")

Same shape again, with one extra ingredient: a decision made once per item. This is the code you'll be specifying, tracing, breaking, and extending in Read the Code: Pass/Fail Counter.
