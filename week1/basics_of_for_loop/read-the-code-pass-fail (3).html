Skill 5 — Compare

Two correct solutions — which would you pick?

Both of these solve the original problem correctly. They're not the same code.

Loop with a counter

pass_count = 0 for score in scores: if score >= 40: pass_count += 1 print(f"Passed: {pass_count}")

List comprehension

pass_count = len( [s for s in scores if s >= 40] ) print(f"Passed: {pass_count}")

Which one would be easier to extend if you also needed the list of passing scores themselves, not just the count?

Both have a case: the loop version already has everywhere you'd need to add a line — drop passing_scores.append(score) inside the if, done. The comprehension would need to change shape entirely: passing_scores = [s for s in scores if s >= 40], then len(passing_scores) for the count. Neither is "wrong" — the comprehension is more compact when you only need a final count; the loop scales more easily once you need to do something with each matching item along the way.
