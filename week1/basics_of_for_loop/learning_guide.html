Variables

No type keyword needed. n = 5 just works — Python figures out it's a number.

Indentation

No curly braces, no semicolons. A : opens a block, and everything inside it is indented — usually 4 spaces.

print() & f-strings

print() writes to the screen. An f-string like f"Lap {i}" drops a variable straight into text.

The for loop

Use for when you already know how many times to repeat something.

for i in range(1, 6): print(i)

This prints 1 2 3 4 5. range(1, 6) counts from 1 up to 6 — the second number is never reached, so it stops one short at 5.

The while loop

Use while when the loop keeps going until a condition becomes false — you manage the counter yourself.

count = 5 while count > 0: print(count) count -= 1 print("Liftoff!")

Each pass checks the condition first. Forget to change count inside the loop, and it never becomes false — that's an infinite loop.

Watch out: the two most common beginner slips are forgetting the : at the end of a for/while line, and mixing tabs with spaces in the indentation. Python will refuse to run until both are fixed.

Both loops repeat code. The difference is who decides when to stop.

for loopwhile loop
Best for A known number of repeats — laps, list items, a fixed range An unknown number of repeats — stop when a condition changes
Counter Handled for you by range() You create it, and update it yourself
Stops when range() runs out Its condition becomes False

Same task, two ways

Both of these add up 1 + 2 + 3 + 4 + 5 and print the total. Same result, different control.

for loop

total = 0 for i in range(1, 6): total += i print(f"Total: {total}")

while loop

total = 0 i = 1 while i <= 5: total += i i += 1 print(f"Total: {total}")
Rule of thumb: if you can say "repeat this N times," reach for for. If you can only say "keep going until something happens," reach for while. The lap tracker in Section 3 knows n up front — which is your first clue about which one fits.
