For Loops & Conditionals

A for loop repeats. An if/elif/else makes a decision. Put them together, and you get the shape behind almost every "go through this list and do something different depending on each item" problem — including both Read the Code exercises.

if / else — two-way

Exactly one of the two branches runs, every time.

if score >= 40: pass_count += 1 else: fail_count += 1

if / elif / else — three-way (or more)

elif only gets checked if everything above it was false. Order matters — the most specific condition goes first.

if temp >= 38: print("Heat Warning") elif temp >= 15: print("Pleasant") else: print("Cold Alert")

Exactly one branch runs

Python checks top to bottom and stops at the first true condition — the rest are skipped, even if they'd also be true.

else is optional

You can have if alone, or if/else, with no elif at all — add branches only when you need them.

Indentation marks the branch

Whatever's indented under if belongs to that branch. A line back at the if's level is outside it.

Combine them

Loop + condition, two shapes you'll keep seeing

Both of these are a for loop with a decision inside it. The number of branches is the only real difference.

Two-way split — counting

pass_count = 0 fail_count = 0 for score in scores: if score >= 40: pass_count += 1 else: fail_count += 1 print(f"Passed: {pass_count}, Failed: {fail_count}")
